# How to Use the D2 Diagram Renderer Plugin for Confluence

This plugin allows you to render [D2](https://d2lang.com/) diagrams directly within your Confluence pages by embedding diagram code in a code block. It is designed to support live updates and accurate architectural visualization.

## Steps to use

1. Navigate to any Confluence page and click “Edit”.
2. Insert a code block and set the language to `d2`.
3. Paste your D2 diagram code inside the block.
4. Save the page — the plugin will automatically render your diagram as an SVG.
5. Edit the code block to update the diagram anytime.

## Tips

- Use Confluence preview to ensure diagrams look as expected.
- Supports most standard D2 shapes, connectors, and style directives.
- Best experienced in desktop view.
