# Privacy Policy for D2 Diagram Renderer Plugin

**Last updated:** May 2025

This plugin does not collect, transmit, or store any personal data.

## Data Handling

- All diagram rendering is performed client-side or within the Confluence environment.
- No diagram code or content leaves your Confluence instance.
- We do not access or log any user activity, document content, or metadata.

## Third-Party Services

This plugin does **not** rely on external APIs or analytics providers.

## User Consent

By using the plugin, you agree to the terms of this privacy policy. If you uninstall the plugin, no residual data remains.
